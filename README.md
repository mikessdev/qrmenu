# QRMenu - Cardápio Digital

QRMenu é uma aplicação web moderna que permite restaurantes criarem e gerenciarem seus cardápios digitais de forma simples e eficiente. Com um design responsivo e interface intuitiva, os clientes podem acessar o cardápio através de um QR Code, proporcionando uma experiência digital sem contato.

## 🚀 Funcionalidades

- Visualização de cardápios digitais
- Interface responsiva para todos os dispositivos
- Categorização de produtos
- Gerenciamento de preços e disponibilidade
- Integração com backend dedicado

## 🛠️ Tecnologias Utilizadas

- Vuejs v3
- TypeScript
- Vite
- Tailwind CSS
- Vuetify
- Outras dependências modernas

## 📋 Pré-requisitos

- Node.js (versão LTS recomendada)
- npm ou yarn

## 🔧 Configuração do Ambiente

1. Clone o repositório
2. Configure as variáveis de ambiente:
```bash
cp .env_sample .env
```

## 🚀 Como Executar o Projeto

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev
```

O projeto estará disponível em `http://localhost:5173`
